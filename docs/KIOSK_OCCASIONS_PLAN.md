# Kiosk 模式 + 场合筛选/当季 Chips — 二轮细化方案（待批）

> 承接 IMPROVEMENTS_DETAIL_PLAN 的 P0-2 与 P1-5，结合 600/600 全图、埋点上线、首页/详情页新布局后的现状再想了一轮。红线不变：无账号无个人数据、确定性、静态客户端、打开即有内容。

## 执行顺序：先 P1-5 后 P0-2

场合数据（600 道全带 occasions 标签）是 Kiosk 吸引屏的内容源——先把场合筛选与当季配置做出来，吸引屏直接复用同一份配置，两件事共享一个真源。

## P1-5 场合筛选 + 当季 Chips

**筛选引擎**：`PlannerFilters.occasions: string[]`；命中规则为「任一所选场合 ∈ recipe.occasions」；URL 参数 `?occasion=cny,party`（分享链接与 campaign 投放链接直接带场合落地）。

**UI 两处**：

1. 筛选面板「风味」组新增「场合」下拉（日历轮廓 icon），九个场合按目录数据自动生成选项——与现有下拉完全同构。
2. **当季 chips 行**：设置行下方一行最多 3 枚（如九月：「中秋家宴」「派对小食」「快手周中」）。点击 = 写入场合筛选 + 换一组；再点取消。选中态用 terracotta 实底，与品牌一致。

**当季配置真源** `src/config/seasonal.ts`：日期区间 → chips 列表（每枚：occasion + 双语文案 + 可选主打菜 slug 列表供吸引屏用）。**租户可在 tenant.json 用可选 `seasonal` 字段整体覆盖**——商场「节庆版」= 改一份 JSON + 投放链接带 `?occasion=cny`，零开发。

**验收**：chips 随系统日期切换；`?occasion=` 链接复现同一专题桌；租户覆盖生效；254 张场合菜图在专题下全真图呈现。

## P0-2 Kiosk 模式

**进入方式**：`?kiosk=1`（demo 域即可现场演示）。首帧在 `<html>` 打 `data-kiosk`，纯 CSS 切换 chrome——同一构建、同一部署，无分支代码。
**实现细节（这次想清楚的坑）**：URL 状态回写 `replaceState` 会重写 query——序列化时必须保留 `kiosk` 与 `src` 参数，否则 90 秒后模式自己消失。

**Kiosk chrome（data-kiosk CSS）**：

- 触控目标全面 ≥56px（下拉、chips、勾选框、换一组）；1080×1920 竖屏实测一档字号放大
- 隐藏：footer 外链、打印、复制链接、存为图片（kiosk 没有打印机和相册）；保留：双语切换、购物清单、路线
- 操作区收敛为三件事：**换一组 · 看路线 · 扫码带走**

**吸引屏（90 秒无交互）**：全屏轮播当季 chips 主打菜的 1280 大图（600 张全图库随便挑，crossfade 8 秒一张，尊重 prefers-reduced-motion），叠「碰一下开始 / Touch to start」。**点某道菜直接进入以那道菜为主打的一桌**（场合预置），不是回空白首页——从一道菜进入一桌菜，比「重新开始」快一步。
**会话重置**：进入吸引屏时清掉筛选状态与本会话埋点节流键——下一位顾客是新会话，计数才真实。

**扫码带走（QR handoff）**：配好一桌后大按钮「扫码带走这桌菜」→ 弹大尺寸 QR（vendored 单文件 public-domain 编码器 `src/vendor/qr.ts`，零依赖零供应链面，SVG 渲染离线可用）。**QR 内容 = 分享 URL + `&src=qr`**——顾客手机扫开即计一次 scan，橱窗到手机的转化闭环全程可测。

**埋点扩展（红线例外内的最小扩容）**：封闭事件集 4 → 6：新增 `kiosk`（吸引屏被点开始 = kiosk 会话数）与 `handoff`（QR 被唤出 = 带走意愿数）。beacon 路由白名单 +2、报告脚本 +2 行标签，仍是无状态计数。**周报由此多出两条商场最关心的数字：kiosk 会话数、橱窗→手机转化率**——这是 campaign 结案报告的主角指标。

**验收**：全触控走通「吸引屏 → 配菜 → 扫码带走」；90 秒闲置复位且模式参数不丢；断网（SW 缓存）下吸引屏与配菜可用、QR 照常生成；手机扫码打开的正是屏上那一桌。

## 体量与顺序

| 步骤 | 内容                                                       | 体量   |
| ---- | ---------------------------------------------------------- | ------ |
| 1    | 场合筛选引擎 + URL + 下拉 + chips + seasonal.ts + 租户覆盖 | 1 天   |
| 2    | Kiosk chrome + 触控尺寸 + 吸引屏 + 会话重置                | 1 天   |
| 3    | QR handoff + 埋点扩展 + 报告脚本更新                       | 0.5 天 |
| 4    | 三档验证（桌面/竖屏 kiosk/手机）+ 三端部署                 | 0.5 天 |

**不做的**：吸引屏视频（图片轮播已足够且离线可靠）；kiosk 专用构建目标（query 参数即可，少一条部署管线）；扫码之外的「发送到手机」通道（邮件/短信都要个人数据，破红线）。
