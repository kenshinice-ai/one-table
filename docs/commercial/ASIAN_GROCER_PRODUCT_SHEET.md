# 一桌 · 门店版 —— 亚超产品说明

> 对象：亚超连锁与独立店主（Box Hill / Glen Waverley / Springvale / Doncaster 等）。
> 多数店主可直接读中文，本文中文为主、关键条目附英文；可原样排版成双面 A4。

## 顾客侧：扫一个码，买齐一桌菜

**Scan one code, shop one table.**

1. 顾客在门口海报 / 收银台立牌 / 购物车贴纸上**扫码**（普通网页，微信里也能直接打开，无需安装任何 App）。
2. 选人数、预算、想吃什么 → **一秒配出一桌菜**：前菜、汤、主菜、主食、甜品，中英双语。
3. 一键生成**购物清单**——所有菜的食材自动合并、按人数换算好分量。
4. **清单按你门店的通道顺序排列**：「3 号通道 · 酱料区 → 冷柜 2 → 蔬果区」，顾客顺着走一圈全部拿齐，还可存成图片离线用。
5. 明天想换一桌？扫同一个码，永远有新组合。

## 店主侧：为什么值得放这个码

| 你关心的 | 一桌带来的 |
| --- | --- |
| **客单价** | 一桌 6–8 道菜 ≈ 15–20 种食材。顾客从「买一样」变成「照单买齐」。 |
| **双语服务** | 界面、菜谱、清单全部中英对照——华人顾客和本地顾客用同一个码。老一辈用中文，子女用英文。 |
| **减少问询** | 「XX 在哪个通道」直接写在清单上，店员少被打断。 |
| **节庆生意** | 年夜饭、中秋家宴、圣诞聚餐专题菜单，挂你的店名做活动——顾客按整桌采购，不是零买。 |
| **备货参考** | 每周一份匿名汇总：本店顾客最常配的菜系与食材榜。不采集任何个人信息。 |
| **过敏原安心** | 顾客勾选排除的过敏原会被规则硬性拦截（含「可能含有」与来源不明），并始终提示核对包装标签——尽责提示做在前面。 |

## 接入流程（一周内上线）

1. **签约当天**：提供门店 logo 与主色，我们出专属版界面与二维码物料设计。
2. **半天现场**：我们的人到店录一次「食材 → 通道」映射（约 150 个条目，货架调整后随维护更新）。
3. **上线**：专属链接（如 `yourstore.onetable.app`）+ 印刷物料源文件交付。
4. **持续**：菜单季度换新、通道变更同步、节庆专题上架——都在固定维护费内。
