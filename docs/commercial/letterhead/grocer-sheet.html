一桌 · 门店版 ONE TABLE FOR GROCERS

扫一个码，买齐一桌菜

顾客在你店里扫码配好一桌菜，购物清单按你门店的通道顺序排好——顺着走一圈，全部拿齐。微信可直接打开，无需安装任何 App。

顾客的一分钟

  1. 门口海报 / 收银台立牌 / 购物车贴纸上扫码。
  2. 选人数、预算、想吃什么 → 一秒配出一桌菜（前菜到甜品，中英双语）。
  3. 一键生成购物清单：食材自动合并、按人数换算好分量。
  4. 清单按你门店通道排序：「3 号通道酱料 → 冷柜 2 → 蔬果区」，可存成图片离线用。

对门店的价值

客单价一桌 6–8 道菜 ≈ 15–20 种食材，顾客从「买一样」变成「照单买齐」。
双语服务界面、菜谱、清单全部中英对照——老一辈用中文，子女和本地客用英文，同一个码。
减少问询「XX 在哪个通道」直接写在清单上。
节庆生意年夜饭、中秋家宴专题挂你的店名——顾客按整桌采购，不是零买。中秋档（9 月 25 日）现在接入正好赶上。
备货参考每周匿名汇总：本店顾客最常配的菜系与食材榜。不采集任何个人信息。
过敏原安心顾客排除的过敏原被规则硬性拦截（含「可能含有」与来源不明），并始终提示核对包装标签。
