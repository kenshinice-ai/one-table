# CNY 2027 春节档创意方向 × 2（谈判用草案）

> 用途：商场谈判时展示「我们不只带软件，带完整 campaign」。每个方向给到主视觉概念、物料清单与 One Table 的接入点；签约后再进设计稿。
> 视觉纪律：campaign 主视觉走 Paradise 制作水准，界面截图保持 One Table 产品色——遵循 BRAND_BRIDGE 双层规则。

---

## 方向一：「一桌团圆 · One Table, One Reunion」（稳妥主推）

**概念**：年夜饭的本质是「把人聚到一张桌上」。主视觉是一张俯拍圆桌——空盘子渐次被菜填满（stop-motion / cinemagraph），桌沿环坐的手伸向同一道菜。One Table 的圆桌 logo（外环是桌、六点是餐位）与主视觉同构，品牌记忆点零成本打通。

- **主视觉**：俯拍圆桌 KV 一套（横/竖/方三裁切），中英双语 slogan：「这桌菜，在 [Centre] 配齐 · Plan it. Shop it. All here.」
- **社媒短片 ×3**（15–30s，竖版）：① 手机扫码→配菜→路线卡跟拍一镜到底；② 三代同堂各自用中/英文界面配同一桌菜；③ stop-motion 空桌到满桌。
- **菜品摄影**：8–12 道年夜饭菜品（Luna-max 图库风格延续，实物拍摄由 Paradise 执行）。
- **场内物料**：扶梯口海报、美食区桌贴 QR、租户门贴「本店食材在一桌路线上 · On the One Table route」。
- **One Table 接入**：年夜饭专题菜单（8/10/12 人桌预设）、限定路线卡春节皮肤（红金描边，仍守双层色律：皮肤属产品层特例，需单独出规范）。
- **报告钩子**：「这个春节，[Centre] 配出了 N 桌团圆饭」——结案标题现成。

**为什么稳妥**：情感普适、执行确定性高、所有素材可复用到中秋/圣诞档换皮。

## 方向二：「六道门 · Six Doors to Dinner」（差异化备选）

**概念**：把「一条路线经过 6 家租户」这个产品事实变成叙事——晚餐不是一次购物，是六扇门后的六段小相遇：肉铺老板的一句火候建议、菜摊的当日鲜、酒行的配餐推荐……每扇「门」是一家真实租户的微型肖像。

- **主视觉**：六格门洞拼版 KV，每格一家租户实景 + 一种食材；中英 slogan：「六扇门，一桌菜 · Six doors. One dinner.」
- **社媒短片 ×3**：每集 20s 跟拍一位真实租户（人物纪实风，Paradise 纪录片能力的直接展示），片尾路线卡收束。
- **租户深度绑定**：六家「门店主角」由中心提名——这是让市场部把租户关系做成内容的机会，也是续约粘性。
- **One Table 接入**：路线卡上高亮六家主角店；「店主推荐」标签出现在对应食材上。
- **风险与对策**：依赖租户配合度（拍摄授权、档期）——合同里写清中心负责租户协调；不确定性高于方向一，报价上浮 15–20%。

**为什么备选**：更有作者性、更能秀制作能力，但执行变量多。给市场部两个选择本身就是专业感——「稳的」和「出彩的」。
