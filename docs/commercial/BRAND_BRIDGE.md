# 品牌桥规范：Paradise 框架 × One Table 产品

> 一页纸，管住所有对外商务物料的视觉。上游权威：`PARADISE PRODUCTION/00 PLANNING 2026/08-品牌识别标准.md`（v1.0）与 `design-system/paradise-production/MASTER.md`。冲突时以上游为准。

## 原则：两层，永不混色

|        | Paradise 层（框架）                                                            | One Table 层（作品）                                     |
| ------ | ------------------------------------------------------------------------------ | -------------------------------------------------------- |
| 出现在 | 信头、封面、页脚、合同、邮件、报价单、结案报告                                 | 产品截图、界面演示、路线卡、分享卡                       |
| 色板   | navy `#0E1729` / paper `#F7F5F2` / 浅底强调 **`#A16207`** / 深底强调 `#F5B335` | 暖米白 `#fffaf2` / 陶土红 `#d96b45` / 鼠尾草绿 `#5a947e` |
| 字体   | Playfair Display + Inter（中文回退宋体/苹方）                                  | Source Serif 4 + Inter（产品自带）                       |
| 标识   | **Lockup A 横版**（日常默认，品牌标准 §3）                                     | 圆桌 mark（只出现在产品截图内）                          |
| 比例   | φ 数列字号、斐波那契间距、61.8/38.2 分栏                                       | 同为 φ 体系（V3 已对齐）                                 |

关系类比：**出版社与书封**。Paradise 是社标与函套，One Table 是书的封面——函套永远不染书封的颜色，书封也不借函套的 navy。产品截图放进信头文档时按「装裱」处理：白/纸色留边，不加 navy 边框叠色。

## 三条硬规则（踩线即返工）

1. **浅底永远 `#A16207`，亮琥珀 `#F5B335` 只许深底**——品牌标准 §2 原文；pitch PDF 多为浅底，这是最容易踩的一条。
2. **数值落 φ/斐波那契档**：间距 8/13/21/34/55/89、分栏 61.8/38.2、字号 φ^(k/2) 数列。「差不多 40」的答案是 34 或 55。
3. **署名格式唯一**：`A PARADISE PRODUCTION · 天域文创出品`，主体行 `PWE Group Pty Ltd · ABN 55 606 664 546`。旧 slogan、旧邮箱、旧电话一律不得出现（品牌标准 §1 废弃清单）。

## 文案骨架

- 一切对外叙事收敛到 slogan：**Create trust through clarity. / 用清晰创造信任。** One Table 的四个可验证事实是它的证词：确定性过敏原拦截、人工审核菜谱、无账号无个人数据、离线可用。
- 身份句（credentials，引用《05-公司介绍-新版》定稿原文，不改写）：视觉制作起家，服务过 BMW、Mercedes-Benz、Porsche、Audi、HSBC、Ray White、PDG、Everland；《奔跑吧兄弟》墨尔本拍摄与央视纪录片参与；2015 SONY 官方视频比赛一等奖。
- 记忆点一句（可用于开场或画册，事实可验证）：**「画出我们翅膀的那条黄金螺线，也画出了这个应用的每一处分栏。」**
