# 店内演示 · 操作手册

## 1. 打开什么

| 场景                   | 网址                                          |
| ---------------------- | --------------------------------------------- |
| **超市橱窗屏（主推）** | `https://demo-grocer.pwestudio.site/?kiosk=1` |
| 商场橱窗屏             | `https://demo.pwestudio.site/?kiosk=1`        |
| 顾客手机（扫码后所见） | `https://demo-grocer.pwestudio.site/`         |
| 公开站（无租户品牌）   | `https://onetable.pwestudio.site/`            |

**屏幕准备**：浏览器全屏（F11 / ⌃⌘F），横竖屏都可以，竖屏 1080×1920 是设计目标尺寸。页面会自己申请**屏幕常亮**，不用改系统设置。首次打开后离线也能用（Service Worker 已缓存），但**第一次一定要联网打开一遍**。

## 2. 三分钟怎么走

1. **静置 90 秒**（或直接开场就让它待着）→ 全屏吸引屏：整屏菜品照片，8 秒换一张，底部「轻触屏幕，开始配菜」。
2. **碰一下屏幕** → 直接进入以那道菜为主打的一整桌，不是回空白首页。**这一步是产品的核心主张**：从一张照片到一桌菜。
3. **点「换一组」** → 同样条件下换一整桌。可以连点几次，说明这是确定性算法不是随机。
4. **点当季 chip**（春节家宴 / 快手周中 / 派对小食）→ 整桌按场合重配，菜单结构一起变（春节是六道有汤有甜，周中是一汤两菜）。
5. **点「购物清单」→「店内路线」** → **平面图**：A1 蔬果、A2 肉档、A3 海鲜、A4 乳品、B1–B3 中间货架、C1 冷冻，红色虚线是按你这桌菜算出的行走顺序，每站下面是可勾选的清单。**这是给超市看的那一页。**
6. **点「扫码带走这桌菜」** → 大二维码，用自己手机扫，手机上打开的正是屏幕上那一桌（含购物清单与路线）。扫码这一下会被记成一次「橱窗→手机」转化。

## 3. 平面图这一版是什么

**是虚构的示意图**，一间典型亚洲超市的布局。要说清楚的是：

- 换成真实超市 = 换一张 SVG + 九个坐标（`tenants/<店>/venue.json`），**不改一行代码**
- 食材到货架的对应关系已经建好（24 条直接映射 + 11 条按品类兜底），换店时基本沿用
- 一间店有平面图就画平面图，没有就自动退回「通道号列表」，两种都能用

## 4. 已知未完成的部分（被问到就这么说）

**新增的 100 道节庆大菜还没有配图**（龙虾、和牛、熟成牛排、烤全羊那一批，图正在产），所以：

- 吸引屏**只会轮播已有照片的菜**，不会出现空白屏——这一条已经处理好了
- 但如果现场手动选到「宴请大菜」或「复活节」，桌上会是灰色占位图。**演示时这两个场合已从当季 chip 行里撤下**，需要主动展示时再用 `?occasion=feast` 打开并说明「这批图下周到」

三个 demo 的当季 chip 行已按「整桌都有真图」挑好：

- 超市：春节家宴 · 快手周中 · 派对小食
- 商场：快手周中 · 派对小食 · 周末早午餐

图到位后删掉 `tenants/<店>/tenant.json` 里的 `seasonal` 字段即可恢复按日历自动切换。

## 5. 出问题怎么办

| 现象         | 处理                                                           |
| ------------ | -------------------------------------------------------------- |
| 屏幕黑了     | 页面已申请常亮；若仍熄屏，是系统电源策略，关掉省电模式         |
| 二维码扫不出 | 手机靠近一些、调高屏幕亮度；文案里也写了这句                   |
| 断网         | 已打开过的页面照常工作，二维码照常生成（编码器在本地，不联网） |
| 想退出 kiosk | 去掉网址里的 `?kiosk=1` 重新打开                               |
| 想从头开始   | 静置 90 秒会自动回到吸引屏，并清空上一位顾客的筛选与计数       |

## 6. 数字（如果对方问效果怎么衡量）

匿名聚合计数，无 Cookie、无个人数据：扫码进入、橱窗屏开始使用、配出一桌菜、打开购物清单、保存店内路线、扫码带走。周报会算出两个数：**橱窗屏会话数**与**橱窗→手机转化率**。`npm run report:campaign` 生成中英双语 A4 报告（需要 Cloudflare API token）。
