# 定价复盘 —— A$999 / A$3,000–5,000 + A$99–199/月

> 你已经把这些数字告诉 Yvonne 了,所以下面不是"要不要报",而是"怎么把它说成
> 一个不会掉价的版本"。结论先给:**结构对,数字低了一个量级,而且低得会伤到你。**

---

## 1. 结构:对的

`setup + 月租 + call-out 单算` 是这类产品的正确形状,而且比一次性买断好:

- 商场买的是**可持续的服务**,不是一坨代码。月租让他们相信明年这东西还有人管。
- **call-out 单算**是专业做法,别改。上门是成本最高、最不可预测的一项。
- 分"联名 / 换品牌"两档也对 —— 差异确实只在设计工作量上。

## 2. 数字:低了,而且是危险的低

### 2.1 A$999 低于他们的采购门槛

Chadstone 是**全澳最大的购物中心**,归 Vicinity Centres(ASX 上市 REIT)与 Gandel
Group 各半持有。这种体量的机构:

- 有**最低合同金额**和采购流程。A$999 不是"便宜",是**小到不值得走流程** ——
  报一千块反而比报一万五更难买,因为它对不上任何一条预算科目。
- 没有人会为一个一千块的项目当 sponsor。而**没有 sponsor 的项目,下一轮预算复盘
  第一个被砍** —— 这正是上一个 AI 工具的下场。

### 2.2 A$99–199/月 覆盖不了你自己列的服务

你在月租里写了:托管、租户变更、季节菜单轮换、**新菜品与摄影**、IT 支持、月度报表。

光是"新菜品与摄影"一项,按你现在的产出节奏(一批 188 张图)就不是 199 块能覆盖的。
结果只有两个:要么你贴钱做,要么你悄悄少做。**后者会让续约谈判变成扯皮。**

### 2.3 定价本身是一个信号

上一个供应商被砍的理由是 **ROI 不成正比**。你如果用 1/50 的价格进场,对方读到的
不是"超值",是"这是个便宜的试验" —— 而便宜的试验没有人会去捍卫。

## 3. 建议的数字

保留低价,**但必须标成"试点价",旁边写上标准价**。否则试点价就是永久价,你没有
涨价路径。

**已写进 proposal 的最终版本**(命名为 Foundation Centre rate):

|                | Foundation(首个中心,本季)        | Standard(公开标准价) |
| -------------- | -------------------------------- | -------------------- |
| 联名版 setup   | **A$999**(你已报,保留)           | A$5,900              |
| 换品牌版 setup | **A$3,000–5,000**(你已报,保留)   | A$16,500             |
| 月度服务 / 屏  | **A$199 / 月**(别报 99–199 区间) | A$590 / 月           |
| 年付 / 屏      | **A$1,990 / 年**                 | A$5,900 / 年         |
| 中秋试用       | **免费一个月**                   | ——                   |

Foundation 价**锁定 24 个月**,不是三个月就跳回去的促销价。

三点说明:

1. **月租报 199,不要报 99–199。** 给区间等于邀请对方砍到下限。一个数字更可信。
2. **REIT 更喜欢年度科目**,不喜欢按月。"A$X / 屏 / 年"和他们买数字导览的方式一致,
   更容易塞进现有预算 —— 尤其是他们**本来就准备花钱做 centre map 的那笔预算**。
3. **试点必须有结束日期和一个事先讲好的衡量指标**,否则免费月会变成永久免费部署。

## 3.1 让低价"合理"的三条理由(已写进 proposal)

只说"因为你是第一个"撑不住采购的追问 —— 对方会问"那标准价凭什么是六倍"。
proposal 里给了三条能自证的理由,而且**第二个中心一条都不适用**:

1. **你们有一部分是拿数据付的。** 现在的平面图是照着公开导览猜的。没有真实租户
   清单和"每家实际卖什么",路线引擎就是有根据的虚构。这份工作让产品变正确,值一个折扣。
2. **你们在承担首次部署风险。** 这东西没在真实商场楼面跑过,一定会遇到没预料到的
   事。风险是真的,就该计价。
3. **我们想要"Market Pavilion 是第一个"这句话。** 不带数字、不带条款,这个 reference
   本身就是我们买的大部分东西。

## 3.2 价值锚点:让他们自己算,不要给行业基准

我没有编任何"业内一般多少钱"的数字 —— 那种数字对方一查就穿帮,而且他们本来就
比我们更清楚。proposal 里改成两个**他们自己手上就有答案**的除法:

- **对比一家租户的租金。** Foundation 价的完整第一年(setup + 12 个月)约等于
  Pavilion 一家租户交给他们的几天租金。
- **对比一次季节营销的制作费。** 不是媒体投放,只是制作。而这个东西跑满四季并且
  会给出数字。

"这两个都是你们的数字,不是我们的。我们宁可你们自己算,而不是听我们说值。"

## 4. 报价单上必须补的几项

- **GST**:所有数字写明 excl. GST,并准备好 ABN 与发票流程。
- **知识产权归属**:代码与菜谱库归你,中心获得使用授权。写清楚,别留白。
- **数据归属**:统计数据归中心,你可脱敏后用于案例。先说好。
- **保修期**:你说的"几个月"要变成一个数字。建议 **3 个月**。
- **SLA**:哪怕只是一句"工作日 24 小时内响应,现场按 call-out 计"。
- **终止条款**:月付、提前 30 天通知即可终止。这条降低他们说 yes 的心理成本。

## 5. 谈判时的一句话

> 免费一个月不是折扣,是把举证责任接过来。一个月后你们看自己楼里的真实数字,
> 而不是看我的提案。

这句话把"便宜"重新框成"自信",是目前这个价位唯一站得住的说法。
